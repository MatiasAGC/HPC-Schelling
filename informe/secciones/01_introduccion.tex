\section{Introducción}

La segregación residencial puede aparecer a partir de muchas decisiones individuales sobre dónde vivir. El modelo de Schelling muestra que incluso preferencias moderadas pueden producir zonas muy separadas a nivel general \cite{schelling1971}.

Este proyecto adapta el modelo a una representación simplificada de Montevideo e incorpora factores sociales y económicos. Su escala y la necesidad de evaluar múltiples escenarios motivan el uso de computación de alto desempeño.

\subsection{Objetivos y contribuciones}

El proyecto aporta una definición precisa del modelo, una versión secuencial de referencia y una versión paralela con MPI y OpenMP. También permite guardar y retomar una simulación, repetir experimentos con los mismos datos y ejecutar varios escenarios de forma controlada. Se compara que las dos versiones den el mismo resultado y se mide su tiempo de ejecución. Las pruebas entre varias máquinas se realizan en FING.

\subsection{Motivación computacional}

La evaluación repetida de vecindarios y destinos tiene un costo suficiente para estudiar memoria compartida y distribuida. El escenario inicial de $1024\times640$ permitió validar el modelo, pero varias restricciones juntas redujeron las mudanzas después de pocas iteraciones. Para la evaluación de rendimiento se agregó una instancia sintética de $4096\times2560$. Esta instancia conserva las proporciones sociales, pero aumenta el trabajo disponible para repartir entre procesos e hilos. El proyecto también permite ejecutar escenarios independientes de forma concurrente.
