# Lista de control del informe

Transcripción normalizada de `Instrucciones/ChecklistInforme.jpg`. Los títulos originales son referencias temáticas y no obligan a conservar una sección independiente.

- [x] Resumen compacto: `00_resumen.tex`.
- [x] Introducción: `01_introduccion.tex`.
- [x] Motivación: subsección de la introducción; debe justificarse con costo medido.
- [x] Teoría y modelo de Schelling: `02_modelo.tex`.
- [x] Funciones utilizadas en el modelo: algoritmo y organización en `04_secuencial.tex`.
- [x] Estructuras de datos: `04_secuencial.tex`.
- [x] Convenciones y simplificaciones: `02_modelo.tex` y `04_secuencial.tex`.
- [x] Estructura del código: tratada por responsabilidades, sin reproducir el código.
- [x] Problemas encontrados: dificultades de implementación en `04_secuencial.tex` y discusión en `09_discusion.tex`.
- [x] Configuraciones utilizadas: `06_metodologia.tex`.
- [x] Evaluación secuencial: `08_resultados.tex`.
- [x] Evaluación híbrida: `08_resultados.tex`.
- [x] Comparación de ambos modelos/versiones: `08_resultados.tex` y `10_conclusiones.tex`.
- [x] Evaluación de si el resultado fue el esperado: `09_discusion.tex` y `10_conclusiones.tex`.
- [x] Trabajo futuro: subsección propia en `10_conclusiones.tex`.
- [x] Referencias: `referencias.bib`.

La marca `[x]` significa que existe un lugar explícito en la plantilla, no que el contenido final ya esté escrito. Los marcadores `\\pendiente{}` de cada sección continúan siendo la lista de trabajo real.
